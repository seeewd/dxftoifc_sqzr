# SPEC 07 — 실측 함정 & 케이스 (구현 시 반드시 숙지)

도면은 두 축이 독립적으로 변함 → **하나의 정답 가정 금지.**
- **기하 위치(패러다임):** 중첩 블록(nested) vs 모형공간 직계(flat) vs 혼합.
- **분류 신호:** 레이어 / 블록이름 / 그룹경로 / 색 — **요소마다 다를 수 있음.**
- **안정신호 = 기하·색**(파일 불문) / **불안정 = 레이어·블록이름**(사무소마다). 이름은 유저가 한 번 지목, 형상은 엔진이 복원.

## 케이스 A — 지하주차장 (nested, 라멘/주차 = 기둥 있음)
`data/지하주차장_평면도_210416.dxf`
- nested(블록 3~5겹), 레이어 **죽음**(구조가 `0`/DEFPOINT) → 기둥 신호 = **블록 이름**.
- **같은 평면 `AB_Pbase`(기둥 948)가 4벌 인스턴스**(겹침2+이동2)=raw 3792 → **평면병합으로 948**(위치 dedup만으론 2844로 과다). 한 층=948(500x700:864,700x700:38,600x600:36,1100x600:10).
- 기둥 footprint = 외곽선(LWPOLYLINE 레이어0) + 중심십자(LINE) + 부호(TEXT, DEFPOINT). **TEXT·DEFPOINT 제외 측정**해야 카탈로그 일치(`기둥 6X11`=1100×600, 이름숫자≠mm).
- 벽은 **`WAL` 레이어 살아있음**(요소별 신호 다름 검증). 건물 61° 회전(평행쌍·중심 로직 회전무관).
- 배치1/배치2 비어있음(viewport0), 전부 모형공간.
- ❌ 스펙초안 오류: "층 Y 445,500mm 스택"·"dedup→312" 둘 다 틀림(=평면 4벌 인스턴스가 진실).

## 케이스 B — 주택 표준도 (flat, 벽식 = 기둥 없음)
`건축분야…0012_평면도.dxf`
- **flat**(모형공간 직계 4.2만 기하, INSERT 20) — load가 직계 수집 못하면 **0개로 읽힘**(과거 버그).
- 레이어 **살아있음**(COL/WAL/INSUL/WID/FIN/CEN…). 색 BYLAYER. 0°/90° 직교.
- **벽식 구조라 기둥 없음.** 레이어명 `COL` = 실은 **구조 콘크리트벽**(이름이 요소를 속임). COL 짧은선 클러스터를 "기둥"으로 오인 주의.
- **벽이 여러 레이어 분산:** WAL만 182벽 vs **WAL+FIN 339**(외벽 마감면). **양끝 긴 골조 외벽은 `COL`에 있음**(COL만 → 긴벽 63개). INSUL=해치 → 페어 0.
- 도면 시트에 **층 평면 3벌 Y로 나란히**(distinct) — flat이라 평면병합(root_idx=-1 단일) 안 됨 → 3벌 다 출력(입력이 3벌이면 정상). 다중평면 선택 UI는 미구현.

## 케이스 C — 컨트롤 테스트 (COL만, 벽 정션)
`test/test.dxf` (COL 1806선만 남김)
- 벽 332 → 정션문제 노출: **L코너 갭(≈두께), T접합 깨짐, 긴벽 단편**(면이 교차부에서 끊김).
- 원인: per-pair overlap 구간만 센터라인 → 교차부 미복원. → **정션 클린업(공선병합+코너연장)** 도입(UPDATE 0001): 332→병합304→코너연장 265끝점.
- 개구부(창/문)가 이중선 끊음 → 단편. 개구부 인식 미구현(작은 갭만 브리지).
