# SPEC 05 — UI (FastAPI + 단일 HTML, 모노톤)

구현: `backend/app.py`, `frontend/index.html`. 진단: `src/preview.py`.

## 백엔드 `backend/app.py`
- `POST /analyze` — DXF 업로드 → `data/uploads/` 저장 → `extract_inventory` → 인벤토리 JSON + `server_path`,`filename`.
- `POST /run` — `{config}` → `run_pipeline`을 **스레드**로 실행, 로그를 **SSE 스트림**(`data: ...`), 종료 시 `event: done`(결과 메타) / `event: failed`. 동시 실행 1건(lock).
- `GET /download/{model.ifc|model_ir.json|debug.log}`.
- `GET /` — index.html. 실행: `python -m uvicorn backend.app:app --port 8000 --reload`.

## 프론트 `frontend/index.html` (단일 파일)
**디자인:** 그레이스케일(배경 `#FAFAFA`, 서피스 `#F4F4F5`, 보더 `#E4E4E7`, 본문 `#18181B`, 보조 `#71717A`, 프라이머리 `#18181B`/호버 `#27272A`, 강조색 없음). 비활성: `#A1A1AA`, opacity .5, "준비중" 뱃지. Pretendard/system-ui. 8px 그리드, radius 8, 1px 보더, 중앙 ~560px 카드.

**화면(위→아래):**
1. 헤더 `POC · 2D→BIM` + 상태(대기/실행중/완료).
2. ① 입력 파일 — 드롭/선택 → /analyze → 요약(단위·paradigm·레이어수/상태·평면다중 경고). *대상층 드롭다운 없음 — UPDATE 0002에서 제거.*
3. ② 요소 매핑 — 기둥/벽 각각 **mode(layer/block/path) + 후보 칩 클릭 선택**. 칩 = 인벤토리 후보(레이어 short+count / 블록 name+크기). 자동제안 = 미리선택(파란 칩). **멀티 선택**. path 모드만 텍스트 입력. 아무것도 안 고르면 벽=평면 전체 선분.
4. ③ 인식 요소 토글 — 기둥(활성)·벽(베타)·그리드/슬래브/보/문창(비활성·준비중).
5. ④ 레벨/층고 — 테이블{이름,EL,층고} +행추가/삭제 **(단일 메커니즘)** + "여러 층 한번에"(N·EL·층고·접두사 → 행 일괄추가). **출력 층 이름은 여기서만 결정.**
6. ⑤ 고급 — recenter, dedup_tol, log_level.
7. `[구축 실행]` → 결과: **디버그 로그 스트림**(레벨별 색, 자동스크롤) + 완료 시 카운트 + model.ifc/model_ir.json/debug.log 다운로드.

**config 빌드:** `srcOf(kind)` = 선택 칩(또는 path 텍스트) → `{mode,values}`. `buildConfig()`가 06_config 형태로 직렬화. SSE는 fetch ReadableStream으로 파싱(EventSource 아님, POST라서).

## 진단 오버레이 `src/preview.py` `render_overlay(cfg, ir, out_png)`
원본 소스 기하(회색) + 인식 기둥(파랑 사각/원)·벽(빨강 센터라인)을 같은 WCS로 겹쳐 PNG. **회색인데 안 덮인 곳=누락.** matplotlib(Agg). before/after 비교·누락 진단용. (IR은 recenter됨 → offset 더해 WCS 복원.)
